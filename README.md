# agent-baza

Базовый кодекс ИИ-агента: как думать, планировать, проверять, говорить и вести процесс.

| Файл | Когда читается |
|---|---|
| `SKILL.md` | Ядро — всегда: принципы, поведение, стиль |
| `stroenie.md` | Когда дело в коде, данных или интерфейсе |
| `process.md` | Когда работа длиннее одного ответа |
| `deploy.md` | Когда выкладываешь, откатываешь версию или чистишь сервер и Docker |

Ядро говорит агенту, когда открыть остальные части, поэтому в каждом запросе лежит только нужное.

Правила написания текстов и чистка невидимых знаков живут в отдельном навыке [infostil](https://github.com/48981/infostil): ядро на него ссылается, ставится он отдельно.

Жанр — документ характера, а не список запретов: связное «кто ты и как думаешь» обобщается на случаи, которых в правилах нет.

## Состав

| Файл · раздел | О чём |
|---|---|
| `SKILL.md` · Принципы | 9 правил мышления: цель, мера, незнание, план, результат, диагноз, простота, суждение, спектр |
| `SKILL.md` · Как действую | 16 правил поведения в пяти группах: безопасность, работа, делегирование, общение, сбои |
| `SKILL.md` · Стиль | Минимализм и инфостиль: суть сверху, таблицы вместо сплошного текста |
| `stroenie.md` | Устройство проекта, программы, тестов, данных и интерфейса |
| `process.md` | 7 шагов ведения работы: план, метрика, файлы проекта, новое и готовое приложение, навигатор, аналитик |
| `deploy.md` | 10 правил выкладки: версии отката, чистка после успеха, проверка перед удалением, неприкосновенные данные, отчёт, сигнал о диске, «имя не роль», одна политика на сервер, чужой деплой (ротация в его репозитории, пока нельзя — отдельный таймер под его замком), копия до удаления |

Ядро заканчивается тремя мета-строками: старшинство правил, пропуск недоступного инструмента, формула написания нового правила.

## Установка

```bash
git clone https://github.com/48981/agent-baza.git ~/.claude/skills/agent-baza
git clone https://github.com/48981/infostil.git ~/.claude/skills/infostil
```

Дальше два способа подключения — можно оба сразу:

**Всегда в контексте.** В `~/.claude/CLAUDE.md`:

```markdown
@~/.claude/skills/agent-baza/SKILL.md
```

**По вызову.** Команда `/agent-baza` либо автоматически, когда задача совпадает с описанием навыка.

**Субагенту** — строкой в его файле `.claude/agents/<имя>.md`:

```markdown
Работай по кодексу: прочти ~/.claude/skills/agent-baza/SKILL.md перед началом задачи.
Сверх кодекса твоё дело — <область>. Успех — <мерило>.
```

## Как править

1. Формула строки: имя-якорь (2–4 слова) · действие в повелительном · граница.
2. Глагол обязателен: констатация читается как лозунг, команда — как инструкция.
3. Граница важнее третьего утверждения — одно «чего не делать» очерчивает поведение точнее.
4. Не дублировать: мысль, уже покрытую другой строкой, усиливать в ней, а не заводить новую. Нужное в каждом ответе — в ядро, нужное по случаю — в отдельную часть со строкой-указателем в ядре.
5. Держать размер: каждая слабая строка размывает сильные.
6. На каждом выходе новой модели сверять кодекс с её рекомендациями по промптам: правило, полезное одному поколению, мешает следующему. Последняя сверка — Claude Opus 5.5 и Sonnet 5.5, октябрь 2026: убраны давление и запреты без причины, описана цель, а не способ.
