# agent-baza

Базовый кодекс ИИ-агента: как думать, планировать, проверять, говорить и вести процесс. Один файл — `SKILL.md`.

Жанр — документ характера, а не список запретов: связное «кто ты и как думаешь» обобщается на случаи, которых в правилах нет.

## Состав

| Раздел | О чём |
|---|---|
| Принципы | 9 правил мышления: цель, мера, незнание, план, результат, диагноз, простота, суждение, спектр |
| Как действую | 24 правила поведения: безопасность, проверка, мнение, поиск, делегирование, обучение, сбои |
| Строение | Устройство проекта, программы, тестов и данных |
| Стиль | Минимализм, инфостиль, легенды к данным, таблицы, схемы, разделение факта и оценки |
| Процесс | 10 шагов ведения работы: план, метрика, разработка, документация, навигатор, лог, аналитик |

Заканчивается тремя мета-строками: старшинство правил, пропуск недоступного инструмента, формула написания нового правила.

## Установка

```bash
git clone <repo> ~/.claude/skills/agent-baza
```

Дальше два способа подключения — можно оба сразу:

**Всегда в контексте.** В `~/.claude/CLAUDE.md`:

```markdown
@~/.claude/skills/agent-baza/SKILL.md
```

**По вызову.** Команда `/agent-baza` либо автоматически, когда задача совпадает с описанием навыка.

**Субагенту** — строкой в его файле `.claude/agents/<имя>.md`:

```markdown
Работай по кодексу: прочти ~/.claude/skills/agent-baza/SKILL.md перед началом задачи.
Сверх кодекса твоё дело — <область>. Успех — <мерило>.
```

## Как править

1. Формула строки: имя-якорь (2–4 слова) · действие в повелительном · граница.
2. Глагол обязателен: констатация читается как лозунг, команда — как инструкция.
3. Граница важнее третьего утверждения — одно «чего не делать» очерчивает поведение точнее.
4. Не дублировать: мысль, уже покрытую другой строкой, усиливать в ней, а не заводить новую.
5. Держать размер: каждая слабая строка размывает сильные.
